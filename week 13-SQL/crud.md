
## CRUD Operations – The Core of Every Database

Every app, website, or software interacts with databases using four fundamental operaKtions:

* **C – Create** (insert data)
* **R – Read** (retrieve data)
* **U – Update** (modify data)
* **D – Delete** (remove data)

Examples:

* **Account**: Register (C), Login (R), Change Password (U), Delete Account (D).
* **Notes**: Write (C), Read (R), Edit (U), Erase (D).
* **Photos & Videos**: Capture (C), View (R), Edit (U), Delete (D).     *
