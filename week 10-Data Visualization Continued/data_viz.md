# Plot Types by Main Classification

Below are the main chart types used in data visualization, grouped by classification. Each entry includes the chart name and a one-line summary of its core concept.

---

## Relational Plot

- **Scatter Plot**  
  Visualizes the relationship between two continuous variables by plotting individual data points on a Cartesian plane[7][1].

- **Line Plot**  
  Shows the trend or relationship between two variables by connecting data points with lines, often used for time series[1][5].

---

## Distribution Plot

- **Histogram**  
  Displays the distribution of a single numerical variable by grouping data into bins and showing the frequency of each bin[5].

- **Box Plot**  
  Summarizes the distribution of a dataset using quartiles, highlighting the median, spread, and potential outliers[5].

- **Violin Plot**  
  Combines a box plot and a kernel density plot to show the distribution and probability density of the data[5].

- **Density Plot**  
  Estimates and visualizes the probability density function of a continuous variable.

- **ECDF Plot**  
  Shows the empirical cumulative distribution function, illustrating the proportion of data points below each value.

- **Strip Plot**  
  Displays individual data points along an axis to show their distribution, often with jitter for visibility.

---

## Categorical Plot

- **Bar Plot**  
  Visualizes categorical data with rectangular bars, where the length of each bar represents the value or count for each category[5][2].

- **Count Plot**  
  Shows the frequency (count) of each category in a categorical variable as bars[5].

- **Pie Chart**  
  Represents parts of a whole as slices of a circle, with each slice proportional to its value.

- **Swarm Plot**  
  Similar to a strip plot, but arranges points to avoid overlap, showing all observations for each category.

---

## Regression Plot

- **Regression Line Plot**  
  Displays the best-fit line for a relationship between variables, used to visualize linear or non-linear trends[3].

- **Residual Plot**  
  Shows the residuals (differences between observed and predicted values) to assess the fit of a regression model.

- **Polynomial Regression Plot**  
  Visualizes a polynomial relationship between variables by fitting a curve to the data[3].

- **Logistic Regression Plot**  
  Illustrates the probability of a binary outcome as a function of a predictor variable[3].

---

## Matrix Plot

- **Heatmap**  
  Uses color to represent values in a matrix, often visualizing correlations or data density.

- **Cluster Map**  
  Combines a heatmap with hierarchical clustering to show patterns in data matrices.

- **Pair Plot (Scatter Matrix)**  
  Displays pairwise relationships between multiple variables in a grid of scatter plots.

---

## Multiplots

- **Facet Grid (Small Multiples)**  
  Arranges multiple plots in a grid, each showing a subset of the data for comparison across categories or variables[4][6].

- **Compound Plot**  
  Combines different plot types or datasets into a single figure, often with custom layout arrangements[4][6].
