# Introduction to Generative AI

## Artificial Intelligence (AI)
- Branch of computer science
- Creation of intelligent agents
- Systems that can reason, learn, and act autonomously

### Machine Learning (ML)
- Subfield of AI
- Trains models from input data
- Makes predictions from new data

#### Supervised Learning
- Uses labeled data
- Predicts future values based on past examples

#### Unsupervised Learning
- Uses unlabeled data
- Discovers patterns and groups in data

#### Deep Learning
- Uses artificial neural networks
- Processes complex patterns
- Can use both labeled and unlabeled data (semi-supervised learning)

##### Generative AI
- Subset of deep learning
- Creates new content based on learned patterns
- Uses both labeled and unlabeled data

###### Types of Generative Models
- Text-to-Text
- Text-to-Image
- Text-to-Video
- Text-to-3D
- Text-to-Task

###### Applications
- Content creation
- Code generation
- Language translation
- Image generation
- Video creation

###### Key Concepts
- Transformers
- Prompts
- Foundation models
- Large Language Models (LLMs)
